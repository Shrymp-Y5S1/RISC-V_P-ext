# RISC-V P 扩展 DSP 调研仓库

本仓库用于沉淀 RISC-V P 扩展（Packed-SIMD / DSP）相关的公开资料研读、专题拆解与阶段性报告，当前调研主线基于 `P-ext-proposal v0.20-draft`。

## 仓库目标

- 汇总 P 扩展公开文档与核心结论，形成统一认知口径。
- 围绕高价值方向做专项调研，支撑后续立项与实现评估。
- 将架构语义、工具链可达性、微架构代价、验证策略与生态信息形成可复用资料。

## 文档口径说明

- 当前讨论对象为草案状态文档，内容可能随标准演进调整。
- 结论默认以“公开可查证据”为基础，建议在文中保留出处与版本日期。
- 对 RV32 与 RV64 差异、双寄存器机制、饱和/舍入边界等高风险点，建议采用独立章节持续维护。

## 维护建议

- 新增专题优先放入 `重点调研方向/`，并保持“问题-证据-结论-风险-建议”结构。
- 原始资料（PDF/TXT）与分析文档分开存放，避免互相覆盖。
- 图片、图表统一放到对应 `.assets/` 目录，保证 Markdown 引用稳定。
- 建议在标题中体现版本与日期，便于追踪规范变化影响。
