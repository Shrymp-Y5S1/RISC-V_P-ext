# L1 助记符可达性 Smoke 报告（WSL2）

日期: 2026-04-07  
范围: 最小子集 10 条 L1 助记符样例  
执行脚本: `scripts/wsl_l1_smoke.sh`

## 1. 目标

验证当前 WSL2 实际工具链对 P 扩展助记符路径（L1）的可达性，输出可追溯的成功/失败记录。

## 2. 执行环境

- OS: Windows + WSL2 Ubuntu
- Kernel: 6.6.87.2-microsoft-standard-WSL2
- Assembler toolchain: GNU riscv64-linux-gnu-gcc 13.3.0 / Binutils 2.42

## 3. 执行命令

```bash
bash scripts/wsl_l1_smoke.sh
```

## 4. 结果汇总

- 总数: 10
- 成功: 0
- 失败: 10
- 失败类型: 全部为 `Error: unrecognized opcode ...`

## 6. 结论与处置

1. 结论: 在当前 WSL2 的 GNU 工具链口径下，L1 助记符路径不可达（10/10 失败）。
2. 处置: 本阶段继续以 L0 `.insn` 路径作为主执行通道，保持语义闭环推进。
3. 后续建议:
   - 若继续推进 L1，可新增 LLVM/Clang experimental-p 口径验证分支。
   - 维持 `scripts/wsl_l1_smoke.sh` 作为固定回归入口，后续工具链升级后复测。
